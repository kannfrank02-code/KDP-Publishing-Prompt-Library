# KDP Book Description Prompt

## Purpose
Write compelling Amazon book descriptions that convert.

## Prompt
Write a persuasive Amazon KDP book description for the book titled [insert title]. Include:
- Hook
- Emotional connection
- Key benefits
- Bullet points
- Call to action

## Example
Output:
Are you tired of chasing love that drains you?

Inside this book, you will learn:
- How to embody feminine power
- How to stop over-giving
- How to attract without chasing
