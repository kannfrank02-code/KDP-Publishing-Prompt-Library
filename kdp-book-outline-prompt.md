# KDP Book Outline Prompt

## Purpose
Create structured, marketable book outlines quickly.

## Prompt
Create a 10–15 chapter outline for a book titled [insert title]. Each chapter should include:
- Chapter title
- Key message
- 3–5 bullet points of content

## Example
Input: Soft Girl Commandments

Output:
Chapter 1: Stop Proving Your Worth  
- Overcompensating in relationships  
- Emotional exhaustion  
- Reclaiming self-worth
